#### Choose and operate a remote executor
Discover an online authorized executor with `executor_list`; call it via `executor_call` using its exact executor ID, generation, profile ID and store ID. Session runtime binding stays frozen. The alternative CLI is `buckyos executor --help`. Management credentials authenticate the daemon; a tool call uses the Agent's App session. After a disconnect, rediscover the active generation and query the original `operation_call_id` with the original `store_id`. Do not replay. A replacement store cannot recover the former ledger.

- **Linux.** Supports exec, read, write, edit, query and cancel. Desktop input and capture are unavailable.
- **macOS 14+ and Windows.** Interactive sessions offer ComputerUse over authenticated `ExecutorCommandStream.computer`. Windows runs foreground `buckyos_agent_daemon.exe`, uses PowerShell, and defaults its ledger to `%LOCALAPPDATA%\buckyos-agent-daemon`. Keep it in the interactive user session. Primary display offers visual, semantic, hybrid and auto observations; click, Unicode type, keypress, line scrolling, delay waits and UI Automation targets (invoke/set_value/toggle/select/expand/collapse). Dragging and pixel scrolling are unavailable. macOS offers semantic observation/targets through Accessibility.
- **Windows diagnostics.** Console helpers launch without a console window; check service logs and stdout/stderr. A long `session.helper` working directory uses its 8.3 short path for xagent while arguments remain session-relative. If unavailable choose a shorter data location. After an input-monitor stall from sleep or debugging, restart the daemon and check readiness; query old operations and observe again.
- **Native computer tool.** A screenshot attaches to `AgentToolResult.images` → `Observation::Success.images`; function calls keep the newest `MAX_TOOL_RESULT_IMAGES`, text behavior loops drop images. Semantic observations produce outline lines following the JSON. Neither a `buckyos computer` CLI nor `--present` bridge is available.
