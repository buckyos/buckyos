# Node Executor

- Source: `doc/arch/node_exector.md`. Owner sudo token manages `nodes/<node>/settings.executor`: `enabled`, `allowed_devices` (exact device DIDs from `devices/<id>/info`), `profiles.<id>` with non-root Unix `run_as{uid,gid}`, absolute `workdir_roots`, `env`, Agent DID `principals`, `ops`, `limits`. Screenshot `capture_size_limit` uses `max_computer_image_bytes` (8 MiB default, 16 MiB max) independently of `max_file_bytes`.
- `owner_agents` controls owner Agents' enabled status, default roots/env/ops (empty ops = all), `computer` max `none|observe|control`, optional `run_as`. Absent = uninitialized, `enabled:false` = admin closed. Desktop seeds it open on first start. Linux seeds once if the owner chose a local account at activation (`etc/host_account.json`); normal user runs in its home without sudo/supplementary groups, root choice gets roots `/root` and `/`. Dev/devtest_ood1 uses the user running `start.py --all`; explicit node settings prevail.
- Scheduler combines policy with Agent assignments into derived `nodes/<node>/config.executor`. Check growing `generation`, `agent-<12 hex>` profile, Agent in `principal_bindings` with `enabled` and `app_installed` true, and moving `auth_valid_until_ms` (30 s lease). A runtime shared by two AgentSpecs is unmapped. Check node `etc/node_executor_acl.json`, node_daemon log `node executor opened, store_id=…`, executor `127.0.0.1:3184`, gateway SOCKS `:3185`. Reinstall clearing `local/node_daemon/executor/` changes store_id; prior runs report StoreMismatch.
- A root Linux/macOS node_daemon switches to profile `run_as`; on macOS choose a dedicated non-admin account (no no_new_privs, uid 65534 has no account). Desktop node_daemon (Windows desktop/macOS LaunchAgent) omits `run_as` and runs with the desktop user's rights; restrict to trusted Agents. Windows uses PowerShell. A mismatched `run_as` (missing on root node unless root was chosen at activation, present on desktop or root-chosen node) or non-root Unix daemon outside desktop mode offers only open_stream/describe/query/cancel. Execution, file ops and workdir resolution return `Capability`.

## URL-issued devices

- Settings → Cluster Manager → Nodes/Devices issues a secret URL. Admin CP sessions manage devices, authorized Agent App sessions execute. Use `buckyos executor --help` and online discovery to select current executor_id, generation, profile_id and store_id. A URL alone does not prove presence. Keep URL secrets private. Retain the original store/op locator for query, cancellation or uncertain input; never substitute a Node DID, silently adopt a new generation/store or replay an uncertain action.
- On target, `buckyos_agent_daemon doctor --json` and `stop --executor <id>` require no Zone login. Expiry, revocation and foreground exit remove availability. Linux desktop is unsupported. macOS 14+ and Windows require logged-in foreground desktop, profile grants `computer_inspect`, `computer_observe`, `computer_act` and ready permissions. Windows uses `buckyos_agent_daemon.exe`, PowerShell 7 or Windows PowerShell, and `%LOCALAPPDATA%\buckyos-agent-daemon`. Session 0, locked/secure desktops and higher-integrity targets are unsupported. Packaged Windows daemon statically links MSVC CRT; Cargo dev builds need VC++ v14 runtime. Inspect `--binary` manifests for dependencies.
- Drivers support primary-display visual/semantic/hybrid/auto observations, click/type/key, line scroll, delay wait, element invoke/set_value/toggle/select/expand/collapse where `inspect` lists them; drag unsupported, no pixel scroll on Windows. Windows higher-integrity windows appear inaccessible without trees. macOS semantic inspection needs Accessibility, visual capture needs Screen Recording; use element click on Chrome links/buttons lacking invoke. Check `inspect` accessibility status.
- Owner `pause|resume --executor <id>` acceptance does not prove cancellation. Check local `instances[].capabilities`, query the original operation, observe again after resuming. User input alone does not pause/invalidate; explicit pause, changed layout/focus or expired observation can stop an action. If a crash lost pending Unicode release data, leave paused/dirty coordination state for owner handling. Windows input-monitor heartbeat gaps (including sleep/debugger) disable desktop access until restart; restart, check readiness and take a fresh observation.
- Native SDK: `ExecutorCommandStream.computer`, `src/kernel/buckyos-api/src/computer.rs`. Check installed verbs before assuming planned `buckyos computer` or `--present` exists. Lifecycle: `doc/arch/agent_daemon.md`.
