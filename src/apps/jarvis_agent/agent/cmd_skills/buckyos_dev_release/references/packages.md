# Build and install details

For an App with Playwright checks, run the project's `npx playwright test` against its built web output before packaging. The matching Chromium and Playwright configuration are in buckyos_app_dev “Page tests”.

- Agent container uses BUCKYOS_APPCLIENT_SESSION_TOKEN (refreshed per shell) and BUCKYOS_TOOL_ENDPOINT. Depending on installed tools it can build Node/npm, Deno and Python/uv projects and test pages; see buckyos_app_dev “Page tests”. Docker, cargo, pnpm, system repos and Zone restart scripts are host work. Host `buckyos --yes <cmd>` uses device identity; host install checks used a user session. For authorized user operations use `--session-token-file <f>` from CP auth.login with `{kind:"system",service_id:"control-panel"}` (repo `doc/sdk/app-dev-quickstart.md` §4). Tokens historically lasted ~15 min. Interactive password login for buckycli on the DV Zone returned AppAccessDenied. Report denied Agent operations with owner commands; preserve identity.
- CLI defaults to cwd and ~/.buckyos_tool. Exit 9 “read access is outside system-default”: use project cwd or `--allow-read <dir>`. stdout is one JSON envelope (ok, data/error, meta.trace_id); progress is stderr. Mounted source `/opt/buckyos/libexec/buckyos-tool/cli/modules/{pikg,pikg_protocol,pikg_archive,app,skill,task}.ts`, error mapping `cli/core/errors.ts`, SDK types `dist/*.d.ts`. For a missing verb inspect app.ts call pattern; use private `$OPENDAN_AGENT_ROOT/tools/<name>.ts` with `deno run --config /opt/buckyos/libexec/buckyos-tool/cli/deno.json`. Leave mounted tools untouched.
- Init kinds include static-web/script/docker/agent-skills/ext-tools; source dir, finished .tar.gz or local image as appropriate. `pikg init` creates app.json and pikg.json in dapp_meta and refuses nonempty metadata. Owner `did:bns:<owner>` → App DID `did:bns:<name>.<owner>`, AppId `<name>.<owner>.bns.did`. Build timestamps change AppDoc object ID unless SOURCE_DATE_EPOCH is set. Info `valid:true` verifies graph/container; `signature_validation:not-present` and `publication_validation:not-checked` identify unverified signing/publication.
- Default CLI timeout 30 s. For async installs, use `--no-wait` then `buckyos --timeout 10m task wait <task_id>`; `app cancel <task_id>` cancels. Existing short App name may resolve to wrong DID (APP_NOT_INSTALLED); use `app status did:bns:<name>.<owner>` or `<app_id>@<owner>`. Static web can show readiness NOT_READY (no instance) or stale gateway content after upgrade; verify response body and user data.
- aiws install returns action installed/satisfied/replaced plus pkg_id/controls, visible in `buckyos aiws library list`; devs can use `buckyos aiws library install <x.pikg>`. Uninstall via `buckyos app uninstall <app_did> --data retain|delete --yes`. In the 2026-10-17 check, delete left `data/home/<owner>/.local/share/<app_id>/` and the script instance volume; check actual leftovers.
- Exit 2 usage (INVALID_OWNER_DID, SCHEMA_VALIDATION_FAILED, ARGUMENT_CONFLICT), 3 auth, 4 permission/confirmation (supply --yes for an authorized preflight), 6 operation (PLAN_REQUIRED, PLAN_NOT_APPLICABLE, PLAN_INPUT_REQUIRED: pass target/install_params through --input; TRUST_RESOLUTION_REQUIRED: missing trusted BNS resolution; INVALID_PACKAGE), 8 timeout (task get before retry), 9 internal/policy.

## Publish an App candidate

`buckyos app publish <absolute dir on control-panel host> --app-doc <template> [--app-type dapp|web|agent|ext_tools]`. Template = dapp_dist/APPDOC.json without pkg_objid. CP must see the source directory; container-local paths do not qualify. It repacks (digests change) and pins `<AppId>.pikg` as repo_content_id in the Zone Repo; repinning the version to different content is refused.

Report publish_status repo_stored_candidate, app_doc_signature not-signed, app_did_publication not-published, pikg_digest and caller-owned pikg_handle. The named store binding at `zone/control-panel/_/pikg_staging` expires at TTL. Install a handle through CP `apps.inspect` with `source:{kind:"local_pikg",staging_handle}`; the CLI install has no handle flag. Owner APPDOC.jwt signing, public upload, BNS/App DID update and readback are unimplemented; DID fetch can still report TRUST_RESOLUTION_REQUIRED. To deliver a transferable package use the locally built file.

Contracts: [PIKG CLI](https://github.com/buckyos/buckyos-websdk/blob/main/doc/modules/pikg.md), [package format](https://github.com/buckyos/buckyos/blob/main/doc/pikg/format.md), [App configuration](https://github.com/buckyos/buckyos/blob/main/doc/sdk/app-package-config.md). Historical check: BuckyOS 0.7.0, Tool/SDK 0.7.131 on test.buckyos.io host (2026-10-17), static/Docker install and upgrade, script install, app publish. Container install and live release workflows were untested.
