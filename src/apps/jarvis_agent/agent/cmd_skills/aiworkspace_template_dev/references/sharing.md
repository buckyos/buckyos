#### Export, share and refresh
`doc.export {mode:"share"|"personal_backup",self_contained?}` returns a seven-day owner exports bucket download (`bucket_id,key,token`). Use `GET https://<zonehost>/bucket/v1/<bucket_id>/<key>?token=<token>` or authorized `buckyos bucket get obj://bucket/<bucket_id>/<key> <file>`. Share exports omit collaboration history; personal backups keep it. Import with `buckyos bucket put` then `ws.import {obj_id,semantics:"new"|"restore",replace?}`. An account can instead supply its own exports `bucket_id,key`; the import consumes that upload. `ws.clone {workspace_id}` makes an independent copy of readable content with `cloned_from` provenance.

`ws.publish {entity_id}` or `buckyos aiws acl-edit publish <path>` requires manage and returns `https://aiws-<id>.<zonehost>/<workspace>/<name>` (`<id>` strips `ws_`). A receiving entity uses `payload.source={kind:"workspace",workspace_id,entity_id,mode:"live"}`, with `zone`/`url` for another Zone. A CSV/JSON/Markdown URL uses `{kind:"url",url}`. Tables need an ID column or `source.def.primary_key`. Only the owner sets the source; `run` on it allows refresh. Source-backed data is read-only. `proc.start {program:"source.refresh@1",params:{entity_id},idempotency_key}`, then poll `proc.get`. `refresh.interval_s` ≥900 enables scheduled refresh. Use `doc.source_query` to read URL table rows. Resolve names with `doc.resolve` and store references (`workspace_id,entity_id,mode,version?`). An object lists actions and risks under `declared.actions`; inspect its capabilities and ask before invoking writes. For an Agent-run fetch program see `aiworkspace_sync`.

#### Roles and access
Check `buckyos aiws acl show <path>`, `acl explain <path> --principal <who>`, `acl who @teachers`, `acl groups` and `acl audit` before and after changes. The nearest path layer wins, then person, groups/`@creator`, `@guest`/`@all`, then deny within the tier. Examples:
```sh
buckyos aiws acl-edit group-add teachers --title 老师 --workspace "$WS"
buckyos aiws acl-edit member-add teachers group:staff,bob --workspace "$WS"
buckyos aiws acl-edit set @teachers /data/成绩 --allow read,update --workspace "$WS"
buckyos aiws acl-edit set @all /data/工资 --deny read --workspace "$WS"
```
Members may be users, `group:<system group>`, `contact:<your did>#<tag>` or `*`. Visitor links require `acl-edit anonymous on`, `@guest` entries and `acl-edit entry-add <group> --methods guest,password`. Only the owner grants or revokes manage. A manager's template/clone/export preserves logical groups, group entries, `@all`/`@guest`/`@creator` and macro bindings. Member lists and individual entries are excluded; newly created groups are empty and anonymous access is off.

#### Toolbar, cover and preferences
Set shared settings using `entity.set_props` on `root`, `key:"config"` and `props:{toolbar:…}` (manage), or on a Surface (structure). `ws.get_info.settings` exposes shared settings. Toolbar zones `title`, `collab` and `tools` take `hidden`, `locked`, `relation` (`inherit|append|override|hide`) and `items`. Items merge by ID or action/args; override replaces order, locked prevents personal switches. A macro button uses `{id:"today",action:"collab.macro",args:{wish:"<id>"},title:"今天的日记",icon:"calendar-plus"}`; a tool uses `block.insert` with `args.entry`. Hide and lock all three zones for App mode. The status bar stays visible. Hiding grants no access.

Import a PNG/JPEG/GIF/WebP/AVIF/BMP ≤8 MiB with `asset.import_object`, then set `config.cover:{object_id}` on root (manage), or `null` to remove it. `ws.list.cover` identifies the image at `/kapi/aiworkspace/asset/<workspace_id>/<object_id>`. Templates, clones and self-contained exports carry bytes. Exports omitting assets list missing covers. Shared settings travel with content and support undo; personal `user.get_prefs`/`user.set_prefs` stay with the person.
