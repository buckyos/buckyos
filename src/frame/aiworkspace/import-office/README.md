# import-office — Word and PowerPoint documents into a Workspace

Implements [Office 导入 TODO](../../../../notepads/done/aiworkspace-office-import-todo.md) (the editable path, §3–§4, and the
sub-documents of §5.3). A dependency-free TypeScript module like `../import-drawio`, `../import-pdf` and
`../import-table`, whose zip reader, XML reader, page plans, `buildOperations`, keys and page layout it reuses: the
Desktop (Vite alias `@office/*`, the parsing in a Worker) and Deno (the Agent command `import_office`, tests) run the same
code. Files import each other with explicit `.ts` extensions.

```text
package.ts     OPC: [Content_Types].xml, relationship parts (targets resolved, external URLs), the main part, which
               Office file a file is (docx / pptx / doc / ppt / odt / odp / rtf; workbooks go to import-table), the
               picker's accept list
units.ts       EMU, twentieths of a point, percentages, angles, on/off attributes
theme.ts       a:theme colours and fonts, the colour map, colour elements and their modifiers (Office's HSL for
               lumMod / lumOff, linear RGB for tint / shade)
richtext.ts    the rich text AST (buckyos.richtext.basic.v1) and a validator mirroring the core's checks
docx.ts        WordprocessingML → a flow page plan: rich text segments and picture segments (§3)
text.ts        DrawingML text: list style inheritance, paragraphs and runs, one string and one style per shape
geometry.ts    the guide interpreter: preset and custom geometry → SVG path data (arcs, flips)
presets.ts     the 187 preset geometries (generated by tools/presets.ts from ECMA-376 presetShapeDefinitions.xml)
pptx.ts        PresentationML → page plans (§4): masters, layouts, placeholders, theme, shapes, pictures, tables,
               charts / SmartArt / OLE, backgrounds
subdoc.ts      one-object docx / pptx (§5.3) for LibreOffice to draw; a stored-zip writer
plan.ts        the plans, the raster request, picture names
operations.ts  a docx plan → commit operations (flow page Blocks); batches by count and size
mod.ts         the public entry
tools/presets.ts   rebuilds presets.ts
tools/import.ts    the Deno host of the Agent command: a file → plans → commits through an AiWorkspace client
```

What the editable path cannot draw — charts, SmartArt without its saved drawing, OLE objects without a preview,
EMF / WMF / TIFF pictures, formulas — goes to the host's `rasterize` as a sub-document; the Desktop has the content
server's LibreOffice turn it into a PDF (nfs_server `repr`, profile `preview-document`) and renders it with pdf.js.
Without LibreOffice those become placeholders (pptx) or are left out (docx) and are reported.

## Test

```bash
deno test -A                          # package / docx / pptx / geometry tests, golden plans of every fixture
OFFICE_REGEN=1 deno test -A           # rewrite ../fixtures/office/expected/*.plan.json after an intended change
deno run -A tools/presets.ts [presetShapeDefinitions.xml]   # rebuild presets.ts (fetched from Apache POI without a path)
cd ../fixtures/office/src && python3 make_docx.py && python3 make_pptx.py && ./make_lo.sh   # rebuild the generated fixtures
```

Where LibreOffice is installed the tests also convert the sub-documents to PDF. `../fixtures/office/docx/real` and
`pptx/real` are files saved by Word and PowerPoint 2007–2016 (and one LibreOffice deck) from Apache POI's test data
(Apache-2.0); `*.lo.*` are the generated fixtures as LibreOffice saves them.
