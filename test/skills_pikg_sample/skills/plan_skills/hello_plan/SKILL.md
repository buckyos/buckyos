# Planning a round of greetings

- One Todo per person to greet, side by side: none depends on another. Give each a manual for printing greetings.
- Each Todo's acceptance criterion: the greeting names that person and the step reported success.
- End with one verification Todo that reads every greeting back and reports which names are missing.
