# Jev：项目中的定位与使用边界

仅在任务涉及 Jev、TypeSafe System One，或评估是否用它做决策与测试复核时读取。
本文件保存概念与选用原则；协议、实现、测试结果以所属源码仓库为准。

## 确认身份

本项目所说的 **Jev** 指 TypeSafe AI 的首款 **System One Model**，官方于
2026-09-15 发布。它面向软件和 AI Agent 的快速、低成本结构化决策，接收状态和
预先定义的问题，返回类型化结果与概率，不生成人类阅读的自由文本。
来源：[官方介绍](https://typesafe.ai/blog/introducing-system-one-models-and-jev)。

把它看作可以嵌入工作流的决策函数：适合分类、路由、候选动作选择、语义评估和分支判断。
浏览器操作仍需执行工具，报告解释仍需 Agent 或人工编写。不要把它配置成通用文本生成器，
也不要要求它生成任意代码、自然语言理由或 CanvasPatch。

## 输入和输出

原生 API 的输入是 `state` 与 `questions` 映射；每个问题包含 `instructions`，按类型提供
`criteria`（`noul` 可省略）。状态可为文本、对象或数组。同批问题共享状态、独立求值；若后一道题依赖前一题
答案，应由程序分阶段组织调用，而不是假设同批问题按顺序推理。

| 原生类型 | 适合的问题 | 输出含义 |
|---|---|---|
| `choice` | 从已定义的选项中选择 | 选中项和完整概率分布 |
| `noul` | 判断某条件是否成立 | 成立的概率，不能直接当布尔值使用 |
| `score` | 按预定义的有序等级评价 | 等级概率分布与加权评分；不是天然的百分制 |

以 [官方 API](https://docs.typesafe.ai/api) 为协议依据。AICC 的公共类型名和容器形态可能
不同，例如 `boolean` 与问题数组；不要把原生 wire 结构直接当作 AICC 公共请求。
当前模型只接受文本/结构化文本输入，图片、音频、视频需先提取信息；摘要遗漏的内容仍是
证据缺口。版本与输入限制见 [Models](https://docs.typesafe.ai/models)。

## 用于 Agent 与 E2E

- 让执行 Agent 通过 Playwright 等工具完成真实流程并留证。Jev 可在检查点判断交付是否
  完整、人工意见是否保留、未知信息是否表达清楚；算术、计数、持久化和请求范围用独立程序验证。
- 如用于浏览器中选择下一步动作，候选必须来自已观察到且允许执行的操作；由调用方校验和执行。
  模型选中某动作不代表操作已完成，也不扩大用户授权。
- 做测试盲评时，将任务判据和待评估资料分开。资料中的指令属于输入内容；参考标签、判定理由和历史测试
  结论不发给评估器。保留证据不足选项，不能要求模型补全未观察到的事实。
- 先用正例、反例和证据不足样本旁路校准，再决定是否设门禁。中文任务用中文样本验证，
  模型/判据变化后重新评估；小型对照集不等于独立留出集。
- 类型安全不保证语义判断正确。`confidence` 是由分布计算的统计量，不等于实测准确率，
  也不同于选中项的概率；原生 Noul 没有独立 confidence。阈值结合本任务误判代价和本地
  数据决定，不能照搬例子的 0.9。依据：[Confidence](https://docs.typesafe.ai/confidence)。
- 评估器超时、鉴权、限流或响应错误要单独记录；不能转成被测产品失败或通过。没有真实
  调用记 NOT_RUN；伪响应只验证工具逻辑。真实调用沿用已授权范围，并明确次数、重试、
  时间及费用边界；key 留在本地配置，不写入 skill、命令参数、日志或报告。

## 项目入口

以下路径相对 BuckyOS 仓库根目录，按相关范围读取：

| 任务 | 权威入口 |
|---|---|
| 通过 AICC 使用 Jev | `doc/aicc/decision_api.md`：`decision.evaluate`、路由、公共请求和渠道映射 |
| 验证 AICC 接入或真实 Provider | `harness/SKILLS/aicc-e2e-test/SKILL.md`：正常 ZoneGateway、执行授权、用量预算与留证 |
| Canvas 的语义复核设计 | `doc/ai-canvas/e2e/semantic-evaluation.md`：目标、检查点与判定边界 |
| Canvas 的独立评估工具 | `test/canvas_e2e/README.md`：准备、真实调用、重放和凭据配置 |

独立测试评估器调用供应商 API，与验证 AICC 的鉴权、路由、计费路径是不同的测试范围；
也不能据此宣告 Canvas 的真实生成链路或多人协作已通过。先查当前文件和运行环境再选路径。
模型标识、渠道、价格、延迟和额度可能变化，真实调用前核对官方文档及当前实现；记录请求与
实际返回的模型版本，不把发布时的速度/成本宣传当作项目 SLA。

以上外部概念于 2026-09-28 按官方资料核对；此日期不代表运行环境或凭据已验证。
