# 流式页交互改进

> 状态：v0.1，已实施，2026-10-12。本文同时是设计说明和实施记录。
>
> 范围：流式页（`layout.mode = 'flow'` 的 Surface），以及富文本和表格两个 Block。参照对象是 Notion。数据模型、协议和存储格式没有改动。
>
> 环境：独立运行的 `aiworkspace` 服务（调试构建）+ Vite 开发服务器，Desktop 外壳用模拟运行时，Chromium（Playwright）。没有在 DV 或真实 Zone 上运行。

## 1. 问题与目标

改进前，流式页上的每个 Block 都包在卡片里：边框、标题栏（标题、类型名、“编辑中”、↑ ↓ ×）、正文区。富文本顶部常驻一排格式按钮，打开时先闪一行“正在载入协作文档…”。表格上方是“N 条记录 + 筛选 / 字段 / + 记录”的按钮条，每行末尾一个“删除”链接，新增记录要填表单。整页看起来像一组表单，不像文档。

本次的目标有两个：

1. 流式页按 Notion 的方式交互。页面就是文档，Block 平时没有边框和控件。工具在用户需要时出现：悬停时出现把手，选中文字时出现格式条，输入 `/` 时出现命令菜单。富文本和表格不再有“进入编辑模式”这一步。
2. 富文本增加“心流输入”模式：像 Windows 记事本一样，在纯文本框里直接写 Markdown 源码，写下的内容随时同步回协作富文本。

## 2. 页面

### 2.1 编辑即输入

编辑子模式下，页面上所有编辑器都是活的（第二期 §8.1 原有规则）。本次把剩下的“编辑状态”去掉：

- 流式页没有 `editing` 状态（`CanvasView.setEditing` 在流式页上不生效）。点击文字，光标就落在点击处。
- 正在输入的 Block 不显示为选中。点进一个 Block 的内容，会清掉页面上的 Block 选中。
- 协作文档打开前，先显示同一段文字的静态渲染，不再出现“载入中”一行。

### 2.2 Block 的外观与把手

- 页面是居中的文档栏，最大宽度 880px，背景为 `--cp-surface`。页面标题 30px，点击即可原位改名，与工具栏的重命名一样以开始编辑时读到的版本为前提。
- Block 没有边框和标题栏。表格、记录、许愿格和扩展 Block 上方有一行标题，点击即可改名（写入 Cell 的 `title`，清空则恢复显示数据名）。没有标题时显示“无标题”。富文本、图片、便签不显示标题行。
- 悬停 Block 时，左边距出现两个把手：
  - **＋**：在这个 Block 下方插入。菜单列出富文本、表格、图片、许愿格、分组和“更多…”（完整插入目录）。只在自由画布上有意义的便签、形状、框、连接线不列入。
  - **⋮⋮**：拖动可以移到页面其他位置，包括分组里（`tree.place`，跨容器时用 `tree.move`）。拖动时显示一条蓝色落点线，靠近页面上下边缘会自动滚动。单击则选中这个 Block，并打开菜单（上移、下移、属性、删除）。
- 分组显示为左侧一条竖线加一行小标题，没有底色。分组末尾的“+”可以把内容加进分组，也可以作为拖入分组的落点。
- 页面末尾是“点击继续书写”区域：最后一个 Block 是富文本时，在它末尾另起一行；否则在末尾新建一个富文本 Block，并把光标放进去。左侧的“+”打开原有的插入菜单（插入目录、分组、已有数据、粘贴）。
- 触摸设备没有悬停，把手保持半透明常显。手机布局收窄左边距，只保留 ⋮⋮。

### 2.3 在用户所在的位置插入

插入可以指定“放在某个 Block 之后”（`CanvasView.insert` 的 `afterId`，排序键取前后兄弟之间）。＋菜单、富文本的 `/` 菜单、插入目录（从 ＋ 菜单的“更多…”进入）都使用这个位置。需要文件的类型（图片）先弹出文件选择，需要已有数据的类型打开插入目录。插入后不选中新 Block；富文本这类插入后直接输入的类型，会把光标放进新 Block。

### 2.4 键盘

| 场景 | 按键 | 作用 |
| --- | --- | --- |
| 富文本或源码框里 | Esc | 离开文字，选中所在的 Block |
| 选中了 Block | ↑ / ↓ | 选中上一个 / 下一个 Block（按阅读顺序，包括分组里的） |
| 选中了 Block | Ctrl+Shift+↑ / ↓ | 把 Block 上移 / 下移一格 |
| 选中了 Block | Enter | 进入它的内容（富文本的光标放到末尾） |
| 选中了富文本 Block | 输入字符 | 字符追加到末尾 |
| 选中了 Block | Delete / Backspace | 删除（原有规则：不删除第一层数据） |
| 选中了 Block | Esc | 取消选中 |
| 选中了 Block | F2 | 打开属性面板 |

自由画布上方向键仍然是移动位置，流式页上不会再把方向键当成移动坐标。

## 3. 富文本

### 3.1 占位提示

空文档显示“输入文字，或输入“/”选择格式”。光标所在的空行在编辑器有焦点时显示提示，按块类型显示为“标题 N”、“列表”、“引用”或“输入“/”选择格式”。

### 3.2 Markdown 快捷输入

规则在输入完成它的那个字符时生效，代码块和行内代码里不生效。

| 输入 | 结果 |
| --- | --- |
| 行首 `# ` `## ` `### ` | 标题 1–3 |
| 行首 `- ` `* ` `+ ` | 无序列表 |
| 行首 `1. ` `1) ` | 有序列表（从输入的数字开始） |
| 行首 `> ` | 引用 |
| 行首 ```` ``` ```` 加空格，或 ```` ```lang ```` 后按 Enter | 代码块（带语言） |
| 空行 `---` `***` `___` | 分割线，光标移到下一行 |
| `**文字**` `__文字__` | 加粗 |
| `*文字*` `_文字_` | 斜体 |
| `~~文字~~` | 删除线 |
| `` `文字` `` | 行内代码 |

规则生效后紧接着按 Backspace，会撤回这次转换，保留输入的字符。另外：

- 在标题、代码块的行首按 Backspace，先把它变成正文。在引用或列表项的第一行行首按 Backspace，先移出引用或列表。这与 Notion 一致。
- 快捷键：Ctrl+Alt+0–3 切换正文和标题 1–3；Ctrl+Shift+7 / 8 切换有序 / 无序列表；Ctrl+E 行内代码；Ctrl+Shift+S 删除线；Ctrl+Alt+M 批注选中文字（没有选中时批注光标所在的块）。
- Esc 不再由 ProseMirror 处理（原来是“选中父节点”），交给页面选中 Block。

实现没有引入 `prosemirror-inputrules`。撤回规则的做法与它相同：反转这次规则的步骤，再插回输入的字符。

### 3.3 `/` 命令菜单

`/` 在行首、空格后、中日韩文字或标点后输入时，会在光标处打开菜单；跟在拉丁字母、数字、`/ : .` 后面时仍然是普通字符，避免误触 `a/b`、`http://` 这类文本。斜杠后面输入的内容用来过滤菜单，可以匹配中文名、英文、拼音和 Markdown 写法（如 `h2`、`biaoti`、`##`）。↑ ↓ 选择，Enter 或 Tab 执行，Esc 关闭（斜杠保留为文字），光标离开或编辑器失去焦点时自动关闭。

| 分组 | 命令 |
| --- | --- |
| 基本 | 正文、标题 1–3、无序列表、有序列表、引用、代码块、分割线、链接对象 / 嵌入 Block… |
| 在下方插入（只在流式页） | 表格、图片、许愿格等标准类型。新 Block 插在这个富文本 Block 之后 |
| 输入方式 | Markdown 源码（心流输入）、批注这一段 |

执行命令时，先删除输入的“/查询”文字，再执行命令。

### 3.4 选区格式条

流式页和数据源视图里没有就近工具栏。原来常驻在文字上方的格式按钮，改为选中文字时浮在选区上方：段落格式、加粗、斜体、删除线、行内代码、列表、链接 / 嵌入、批注。自由画布不变，这些工具仍在就近工具栏里，并多了一个“Markdown 源码”按钮。

只有光标、没有选区时，批注用 Ctrl+Alt+M 或 `/` 菜单的“批注这一段”，插入对象链接或嵌入用 `/` 菜单的“链接对象 / 嵌入 Block…”。批注读取选区时优先使用浏览器的选区（包括只有光标的情况），因为编辑器内部的选区会比点击稍晚更新。

格式条和 `/` 菜单画在应用根节点里，不会被自由画布上的 Block 或页面滚动区域裁掉，并随滚动重新定位。`/` 菜单靠近窗口底部时向上展开。

### 3.5 粘贴 Markdown

粘贴内容只有纯文本、并且看起来像 Markdown 时（有标题、列表、引用、代码围栏、表格行、加粗、行内代码或链接），会转换成富文本。转换用的是内核的 CommonMark + GFM 转换器，与许愿格结果写入用的是同一个。Shift+粘贴，或者光标在代码块里时，按原文粘贴。

## 4. Markdown 源码（心流输入）

### 4.1 交互

- 入口：富文本右上角悬停时出现的“MD”按钮、Ctrl+/、`/` 菜单的“Markdown 源码”、自由画布就近工具栏的同名按钮。再按一次回到排版视图（按钮显示为“排版”）。
- 源码模式下，富文本区变成一个纯文本框：等宽字体，没有工具栏，不做任何自动转换，Tab 输入制表符，高度随内容增长。浏览器自带的撤销 / 重做对它有效。
- 停止输入约 350ms 后，以及失去焦点、离开源码模式时，修改会写回富文本，走原来的协作提交路径（Loro → `richtext.apply_update`），保存状态、离线副本、草稿和锁的规则都不变。
- 进入时，光标放在排版视图里光标所在块的末尾。离开时，排版视图的光标放在源码光标所在块的末尾。
- 对象链接写成 `[名称](entity:<id>)`，嵌入的 Block 单独占一行 `![嵌入 · 名称](embed:<cell id>)`，转换回来时都会还原。

### 4.2 同步算法

目标是用户写下的文本在光标下不被改写，同时每次修改只影响它碰到的块：

- 源码被切成段，每个顶层块一段，段之间的空白原样保留：`text = gap₀ + seg₀ + gap₁ + … + segₙ₋₁ + gapₙ`。
- 一次修改（旧文本 → 新文本）按公共前缀和后缀缩成一个变化区间。只有和这个区间相交的段会重新解析，替换编辑器里对应的块。其他块，包括它们的 id、批注锚点，以及同事同时做的修改，都不受影响。
- 重新解析出的块尽量继承原来的 `block_id`：内容相同的先配对，其余按类型顺序配对，并递归处理子节点。所以只改了几个字的段落、标题、列表会保留原 id，挂在它们上面的批注仍然有效。
- 用户输入的文本就是新的源码。即使转换会规范化写法（例如 `* ` 规范成 `- `），也不会回写到文本框里。
- 别处来的修改（同事、撤销、版本恢复）：哪个段对应的块变了，就只重新生成那一段的文本，新出现的块插在前一个块的段之后。如果块的顺序被别处改了，就整篇重新生成。文本框按变化区间替换，并保持光标位置。如果用户手上还有没写回的输入，先写回，再合并别处的修改。IME 组合输入期间不改动文本框。
- 实现：`richtext/markdownSource.ts`（切段、`applyEdit`、`rebase`）、`richtext/EditorMenus.tsx`（`MarkdownSourceEditor`）。排版视图的 ProseMirror 在源码模式下仍然挂载（隐藏），它是与 Loro 绑定的唯一入口。源码模式下不显示批注卡片，切回排版视图后照常显示。

### 4.3 模式记忆

是否处于源码模式，按富文本实体记在本机的 `localStorage`（`aiworkspace.md-source`，最多 200 条），只是本机的偏好，不写入工作区。

### 4.4 已知限制

- 同一段落两人同时修改时，后写回的源码以块为单位覆盖。排版视图是字符级合并，源码模式只能做到块级。
- Markdown 无法表达的属性在被修改的段里会丢失，例如有序列表的 `start` 以外的属性、表格单元格的 header 标记（GFM 只认第一行）。没有被修改的块不受影响。
- 一次停顿内在相距很远的两处修改时，两处之间的块会一起重新解析。内容不变的块保留 id，但同事在这期间对它们的修改会被覆盖。

## 5. 表格

### 5.1 外观

- 表格是数据库网格：只有上下边框和列之间的竖线，没有外框。表头是浅色文字，每列前面有类型图标（文本、数字、日期、单选、多选、勾选、对象引用）。
- 单选和多选显示为色块，同一个选项的颜色固定，深色主题有单独的色值。布尔值显示为勾选框，点一下就写入。
- 在流式页上，筛选 / 排序和字段两个工具放在表格标题行的右侧，悬停时出现。“N 条记录”放在底部右侧，同样悬停时出现。数据源视图里这两个工具始终可见。
- 正在编辑的单元格是贴合格子的输入框，带强调色描边。获得焦点的单元格有描边。

### 5.2 新建记录、字段与删除

- 勾选框点击后立即显示新状态，写入完成后以存储的值为准。
- 行下方的“+ 新建”：点击后出现一行输入，填写标题字段后按 Enter 插入记录，输入行保持打开，可以接着写下一条，Esc 关闭。没有标题字段时直接插入一条空记录。除标题外还有其他必填字段时，打开原来的新增记录表单。
- 表头最后一列的“+”：输入字段名，选择类型，就能添加字段（`fieldOps.addFieldOps`，与字段管理器共用。视图显式列出列时，新字段在同一次提交里加入视图）。改名、改类型、选项管理仍在字段面板里。
- 删除记录：悬停在行上时，行尾出现删除图标，替代原来每行的“删除”链接。
- 自由画布上不显示底部这一行，新增仍走就近工具栏的“新增记录”。

### 5.3 键盘

| 按键 | 作用 |
| --- | --- |
| 方向键 | 在单元格之间移动；目标行在虚拟滚动窗口外时先滚动过去 |
| 输入字符 | 用这个字符开始编辑（文本、数字类字段） |
| Enter / 单击 | 编辑；编辑中按 Enter 提交，焦点回到单元格 |
| Tab / Shift+Tab | 提交并移到右 / 左边的单元格 |
| Delete / Backspace | 清空单元格 |
| Esc | 取消编辑；在页面上再按一次，选中表格所在的 Block |

## 6. 记录、图片与嵌入

- 记录在流式页上显示为 Notion 式的属性列表：左边是属性名，右边是值，悬停时值所在行高亮。
- 图片在流式页上按原始尺寸显示，宽度不超过文档栏，高度不超过 520px，不再撑满整栏。文件信息和“替换…”悬停时才出现。
- 富文本里嵌入的 Block 去掉了虚线框，只在悬停时显示细边框。标题改为“↗ 名称”，“只读”的说明移到提示文字里。

## 7. 对其他视图的影响

- 自由画布：富文本就近工具栏的顺序改为“段落格式”在最前，并增加“Markdown 源码”按钮。快捷输入、`/` 菜单（不含“在下方插入”）和源码模式在画布上同样可用。表格换成了新网格和类型图标；“+”列和行删除图标在有对应权限时显示。
- 数据源视图：富文本和流式页一样使用浮动格式条和 MD 按钮；表格使用新网格、底部新建行和表头“+”列。
