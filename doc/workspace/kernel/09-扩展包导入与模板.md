## 扩展包与工作区扩展集合

扩展机制提供增加 Block、Block control、Source adapter、Importer 和 Workspace template 的统一入口。扩展声明自身的数据、界面与执行契约，宿主提供加载、校验、挂载管理、版本管理及提交能力；扩展不能增加未经定义的数据原语或绕过权限、事务和资源管理。

### 包结构与贡献类型

分发复用 PIKG 的归档、内容身份与安装体系，沿用 `app_type: aiws`、`pkg_list.aiws` 和 `aiws-manifest.json`。`aiws-ext` 仅可作为扩展集合的概念名称，不另设同义 wire 类型。`.pikg` 交付可复用扩展，`.bcanvas` 交付工作区内容，两者不合并成一种包。

PIKG 的外层封装沿用包协议；AIWS payload 的公共结构为：

```text
aiws-manifest.json
controls/<目录>/
  component.json
  <entry 声明的 HTML/CSS/JS、声明式或 composition 文件>
  <源码与资源文件>
templates/<id>/
  snapshot.json
  objects/<object id>
  chunks/<chunk id>
```

控件清单与入口按 [component Schema](../../../src/frame/aiworkspace/schemas/component.schema.json) 解释，包中控件和模板目录由 [AIWS manifest](../../../src/frame/aiworkspace/schemas/aiws-manifest.schema.json) 索引，模板快照遵循 [template Schema](../../../src/frame/aiworkspace/schemas/template.schema.json)。纯控件包的模板集合为空；只依赖内置标准库的模板可以不携带自定义控件。Source adapter 与 Importer 的独立贡献入口通过明确的新清单版本加入，不向旧版本任意塞入未声明字段，也不伪装成 HTML 控件来取得后台能力。

AIWS 清单承载以下契约信息；这是贡献模型，不要求所有贡献类型在本版本已经有可用实现：

| 内容 | 必须表达的语义 |
| --- | --- |
| 包与扩展身份 | 稳定标识、发布版本、来源与内容摘要；显示名称不能代替身份 |
| 宿主要求 | 清单版本、所需宿主 API 版本、必需与可选能力 |
| 贡献入口 | Block、control、Source adapter、Importer、template 等贡献的类型与稳定身份 |
| 公开契约 | 属性、数据绑定、事件、内容 slots、输入输出及适用条件 |
| 实现与资源 | 固定修订的声明式定义或程序、源码快照、图片、预览及其他运行资源 |
| 依赖 | 贡献之间的确定版本关系、依赖闭包及冲突规则 |
| 执行要求 | 需要的宿主能力、执行位置和资源类别；不包含授予这些能力的凭据 |

不同贡献使用各自有版本的内容 Schema，共用身份、依赖、安装与引入机制。未知必需能力必须明确拒绝激活；未知可选能力仅在定义了回退时可忽略。不能静默忽略一个 Source 或模板入口后报告整包能力全部可用。

依赖必须解析到确定修订；运行中的 Workspace 不随外部包的 `latest` 自动变化。首版分发采用自包含依赖闭包，必要第三方定义与资源以快照携带；不要求 PIKG 为此引入自动跨包安装。依赖环与版本冲突应在引入或升级时发现。

控件定义依赖图与模板内容图分别收集，再按内容身份共享资源。某个测试实例绑定的业务表不自动成为控件包依赖；模板仅携带明确选入的初始数据，不复制开发者授权、凭据、草稿或运行记录。

### 安装、引入、实例化与运行

| 动作 | 产生的结果 | 生命周期边界 |
| --- | --- | --- |
| 安装到本机库 | 为当前用户登记包及可发现贡献 | 不创建 Workspace，不执行包内业务动作 |
| 引入 Workspace | 将选择的定义、实现与依赖固定到工作区扩展集合 | 资源属于工作区闭包，不依赖安装者机器持续在线 |
| 实例化 | 根据定义创建 Block、control、Source 配置或模板内容 | 参数、绑定、目标位置和数据归属明确；不隐式执行任务 |
| 激活或运行 | 在指定宿主内运行获准贡献 | 使用当前执行身份与能力，不使用扩展作者凭据 |

工作区内已引入的定义是协作者共同读取的文档内容。本机包升级或卸载不修改既有 Workspace；另一位协作者无需在自己的本机库安装同一包即可使用工作区已持有的定义。缺少宿主能力时保留定义和实例数据，按声明显示回退。

同一工作区内，同一扩展身份对应一个确定定义；相同来源、发布版本和摘要可复用，不同版本进入显式升级。相同发布身份及版本却声明不同来源摘要应拒绝，不能通过名称相同静默覆盖。

实例化区分定义默认值、实例覆盖与用户内容。不同实例的私有内容独立创建，显式共享的数据绑定继续共享。模板包可以只引用内置标准库，不必虚构一个自带控件。创建多个模板实例时分别建立工作区身份与可变内容。

### build、升级与迁移

扩展开发遵循“编辑工作副本 → build → 原子生效”。开发者或 Agent 可以在获准的源码目录编辑；文件保存只更新工作副本，Workspace 保存通过 build 的完整快照。目录的本机绝对路径属于个人配置，不写入共享定义。

一次 build 固定源码与资源清单、依赖修订和目标定义基准，完成结构、宿主能力、接口与资源校验。资源先可靠就绪，再通过一次 Commit 更新定义、源码快照、实现资源引用和构建来源记录；失败保持上一个有效定义，不留下半套共享状态。

build 不是任意服务端脚本执行入口。用户构建程序若需要运行，应进入获准执行环境；提交服务负责校验和接收产物。工作区不得因 build 请求而无条件执行包提供的安装钩子。

并发 build 使用定义与依赖版本前置条件。基于过期定义的更新必须显式冲突，不能覆盖另一协作者的有效修改。来源升级需列出本地修改、影响实例和接口变化；源码工作修订与来源发布版本分别记录。

兼容更新保留实例 ID、属性覆盖、绑定和用户内容。删除已使用 slot、收紧必填参数或改变实例结构，需要确定的迁移计划；定义变更与必要数据迁移共同校验、共同提交。无法迁移时拒绝升级，并继续使用旧定义。

重新挂载必须清理旧订阅、定时器和运行上下文，拒绝旧 runtime 的迟到回调；不能因收到同步、重连或重载而再次执行业务动作。已开始的任务记录其使用的实现修订，后续新事件才采用新实现。固定发布与历史回放保留原修订。

移除仍被实例或其他定义强引用的扩展必须拒绝，或在同一事务中完成替换、解绑与迁移。本机卸载不删除工作区定义；工作区删除定义不等于立即回收仍被历史或快照保留的资源。

## 可扩展 Import 框架

Import 框架负责输入发现、导入器选择、交互、转换结果和提交；具体文件格式的识别与解析由 Importer 提供。内置导入器和扩展导入器遵守同一契约，现有导入入口统一接入该框架，不保留各自独立的权限与写入通道。

### 输入、识别与目标选择

文件、文件夹、剪贴板与拖放是输入通道，不是不同的导入架构。宿主提供输入描述、可读取的内容、媒体类型、文件名及用户上下文；Importer 只能读取获准输入，不能因解析一个文件获得任意本机路径或剪贴板访问权。

格式识别结合内容特征和元数据，文件扩展名仅是线索。探测阶段应有时间、读取量和资源限制，不修改 Workspace，也不执行业务副作用。

Importer 声明支持的输入类型、可产生的目标类型、转换能力及所需选项。探测返回可解释的候选及识别依据；同一输入可被多个导入器识别，也可由一个导入器转换为多个目标，例如图像、可编辑对象或资源附件。

存在多个有效导入目标时，宿主统一展示导入向导，由用户选择目标、页面或数据位置、转换参数和损失处理方式。单一且明确的候选可使用已确认默认值；不得为了省略向导悄悄选择有损目标。

### 转换与提交

```text
取得获准输入 → 探测候选 → 选择目标及参数
       → 生成候选内容与损失报告 → 暂存并校验资源
       → 规划 ID、引用与目标位置 → 确定导入计划（必要时确认）
       → 条件 Commit → 返回实际创建或修改的对象
```

转换产出候选数据、Block/布局、资源和来源说明，不直接写数据库。需要昂贵计算、联网或专用解析程序时，转换使用受限任务环境；后端数据服务不加载任意格式解析脚本。

候选内容需明确列出未支持元素、近似转换、精度或排版损失、截断与缺失资源。不能将 CAD 的静态预览报告为完整可编辑模型；可把 AutoCAD 等格式作为扩展 Importer，实现其声明的转换范围，并按策略保留原文件供追溯或再次转换。

将子图导入现有 Workspace 时，一次生成稳定的新 ID 映射，统一重写父子关系、定义引用、数据绑定、内部链接与连接线端点。内部共享关系保持一致，外部引用保留其明确身份及授权要求，不根据名称猜测绑定。整包恢复和工作区 Clone 使用各自文档协议，不与子图粘贴混用身份规则。

资产先经统一资源通道暂存并获得可验证引用。上传成功不等于导入成功；定义、数据、布局和引用的正式变更在资源就绪后进入同一逻辑提交。失败不发布半份结果，暂存物按保留与过期规则清理。

导入计划固定目标位置、定义版本、相关读条件及幂等身份。等待确认期间目标发生变化时重新校验；网络结果未知时查询原接受事实，不用新身份重复插入。需要分批的大导入必须声明批次及可恢复进度，不能把部分提交称为完整原子导入。

### 导入语义

普通值导入创建内部可写数据。导入 CSV、XLSX 或其他文件不会自动建立 Source、持续同步或回写原文件；“订阅外部来源”必须由用户显式选择，并转入 Source 的配置与授权流程。

从剪贴板粘贴 AIWS 自身子图时，应复用复制/粘贴的归属及 ID 映射规则；从外部应用粘贴内容时走格式探测与转换。两者可以共用宿主入口，但不能丢失内部对象的结构语义。

Importer 的实现、输入规范与目标 Schema 分别版本化。旧工作区保存的是已导入内容及必要来源，不要求未来重新运行旧 Importer 才能显示。再次转换或刷新是新的显式操作，不能在打开旧文档时自动改写内容。

## 模板、工作区 Clone 与业务实例

模板是一份具有初始化和输出约定的 Workspace，不另建文档格式。

工作区 Clone（`ws.clone`）把一个 Workspace 复制为调用者拥有的新 Workspace。它是物化复制，不是写时复制：

- 先把调用者读得到的内容物化成一份快照，再装入成新的 Workspace：新的身份和 epoch，独立可写的内容和提交历史，富文本从新的 lineage 开始。读不到的实体不复制，在结果里列出。
- 不可变对象在 named store 里共享；逻辑数据是独立的一份，副本的完整内容按自己的逻辑占用计量（[权限、资源与保留](11-权限资源与保留.md)：资源归属独立于底层是否去重）。
- 内部引用不带 `workspace_id`，复制后仍指向新文档；外部引用保留原目标。
- 只记一条来源 `cloned_from`（来源 Workspace 和快照），作为出处。新旧 Workspace 之间没有同步、合并或上下游关系，来源被删除不影响副本。
- 调用者要能拥有 Workspace，并在源 Workspace 有工作区级 `export`。

Clone 保留布局、Renderer、共享结构和必要 Schema；不继承组成员、单人条目、匿名访问开关、分享入口、发布、凭据、Session、私有草稿、个人作用域实体、旧运行、托管配置、名字或已通过审核等过程状态；副本里的实体都记为发起 Clone 的人创建。外部 Source 重新校验访问和刷新能力。新建方式的导入（`ws.import new`）按同样规则装入，并把包里的快照记为 `cloned_from`。

**权限设计**（逻辑组的定义；授给逻辑组和 `@all`、`@guest`、`@creator` 的允许与拒绝条目；宏的组绑定，见[权限、资源与保留](11-权限资源与保留.md#workspace-权限组)）随模板、Clone 和导出包传播，前提是导出者对源工作区有 `manage`：只有 `export` 的人得到的副本、包和模板不带权限设计。模板把它写在 `templates/<id>/permissions.json`（`{ format: "aiws-permissions/1", design }`，受模板 digest 保护）；包写在 manifest 的 `permission_design`；条目的资源不在快照里的，导出时报告并丢弃，模板里不会有授给单个调用者的条目。装入时原样建组、写条目和绑定，组成员为空，公共匿名访问关闭。模板升级不静默修改已有实例，迁移须显式进行。

“克隆”在 AIWS 里还有三种用法，与工作区 Clone 不是一回事：

| 说法 | 是什么 |
| --- | --- |
| 工作区 Clone（`ws.clone`） | 复制整个 Workspace 为新的 Workspace，见上文 |
| `tree.clone` / `entity.clone` | 工作区内复制一棵子图的 Commit 操作，见[数据模型与引用](02-数据模型与引用.md) |
| 放映克隆（`clone_for_show`） | 实时放映时冻结的只读基线，见[演示与打印](10-演示与打印.md) |
| 会话的运行工作区（`clone_for_session`） | 演示会话复制出的运行 Workspace，见[演示与打印](10-演示与打印.md) |

复杂业务可以用模板实例承载独立材料与审核；简单业务可以用共享 Table 加受限表单。两者都由相同内核组合，不强迫所有流程变成一张表。

审核确认绑定确定版本，后续草稿不能继续冒充已确认内容。汇总固定所用实例与确认版本集合，记录作用域、时间口径、覆盖限制和失败项。发现索引可重建，不应独占文档语义；普通私人 Clone 不自动登记成业务提交。

受限表单在权威边界校验字段白名单、追加权限与幂等。表单访问者不因可追加而读到整张表；跨实例汇总也不越过各实例的授权。
