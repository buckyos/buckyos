## Block 与 Renderer 宿主

Block 是工作区内可定位、绑定、呈现和操作的界面实例。Renderer 决定一个 Block 如何呈现；宿主提供数据、模式、几何、权限、状态和命令能力。内置代码、声明式定义与 HTML 实现遵循同一宿主契约，HTML 是实现方式之一。

### 定义、实例与公开接口

Block 定义包含稳定类型身份、版本、接受的数据类型、公开属性、命名绑定、呈现能力及宿主 API 要求。Block 实例保存定义引用、属性覆盖、绑定、布局与文档关系，不复制一套独立的业务数据模型。

| 契约 | 冻结要求 |
| --- | --- |
| 身份与版本 | 类型身份、发布版本、工作区定义修订和所需宿主 API 分别表达，不以标题作为身份 |
| 属性 | 声明类型、默认值、校验与编辑方式；实例覆盖与定义默认值分开保存 |
| 数据绑定 | 使用命名绑定，声明接受类型、必填性及读写意图；运行时再按当前权限取得有效能力 |
| 呈现入口 | 至少有安全的静态表现；可提供简化、查看、编辑、属性面板和打印表现 |
| 几何能力 | 声明默认/最小尺寸、缩放或重排方式、形状与连接锚点；父容器决定最终布局 |
| 生命周期 | 接收挂载、输入变化、尺寸/模式变化、暂停及卸载；释放订阅、计时器和执行资源 |
| 交互能力 | 动作、事件、快捷键和工具栏使用统一事件与动作模型，不直接调用宿主内部组件 |
| 成本声明 | 声明编辑器、HTML、媒体等运行成本，由宿主决定激活、降级与挂载数量 |

实例化应形成一次可校验的操作组，原子创建必要数据、Block 与绑定。新建实例不等于执行其中的宏或业务动作。

同一份数据可由多个 Block 呈现。颜色、标题覆盖、图表参数等展现配置保存在实例或共享附加层，不污染被绑定的数据字段。

### 呈现、编辑与测量

`Static` 是无业务副作用的静态表现，不启动许愿格、宏或媒体播放；复杂 HTML 可以使用对应版本的静态快照。没有快照时显示可解释占位，不能为取得预览而自动运行未知代码。

`Simplified` 服务于缩略、低缩放或预算不足场景；`View` 提供查看时的可交互表现；`Editor` 提供内容编辑；`Inspector` 编辑实例属性和绑定。缺少某入口时回退到静态表现，不能继承另一模式的写入行为。

宿主传入经过授权的数据投影、数据可用性、实际能力、只读原因、尺寸、缩放及当前模式。Renderer 不直接持有数据库连接，也不能从“处于编辑模式”推导出写权限。

尺寸测量必须有明确输入和适用范围。可测量文本在宽度约束内报告固有尺寸；不能可靠测量的媒体、HTML 或专用 Block 使用明确尺寸或声明的宽高比。布局不得依赖无限次 DOM 试探，也不得在测量时产生共享写入。

渲染和测量结果属于当前布局计算，用户显式调整的尺寸属于文档。测量完成不自动把每个客户端算出的像素值写回共享状态。

### UI State 与写入通道

| 状态 | 所属位置 |
| --- | --- |
| 默认样式、实例属性、绑定、保存的展现配置 | 共享文档，经过 Commit |
| 用户列宽、个人折叠偏好、尚未提交的表单草稿 | Workspace + User + Block 的私有状态 |
| hover、按下、焦点、拖动预览、当前选区 | Session 临时状态 |
| 任务进度、候选结果、错误与取消状态 | 运行记录，不混入 Block 正文 |

共享编辑通过 Command Bridge 提交；私有持久状态通过 User State 接口保存；纯交互状态留在当前会话。相同的“折叠”或“选项”可以按用途进入不同状态域，但其定义必须明确，不能由组件临时决定。

准备计划、显示预览和客户端校验都不免除服务端准入。编辑器被暂停或卸载前应保留尚未提交的输入，卸载不能等价于丢弃草稿。

### HTML、版本与回退

HTML Renderer 运行在页面内的同源 iframe 中。iframe 负责样式隔离、崩溃隔离和挂载管理，不是安全边界：HTML 代码与页面脚本同权，可以用当前用户的会话访问该用户有权访问的内容。宿主经 `window.aiws` 提供带版本的 API，写入经 Command Bridge 走正常的权限、锁、撤销和保存状态；这保证规范的写入路径，但不限制代码的能力。

信任在引入时决定。内置 Block 随系统发行，视为可信。扩展定义在 Workspace 内 build 或 import 需要所在文件夹的 `structure` 或定义的 `update` 权限；执行这一操作就是为全体协作者引入这段代码，信任根是 Workspace Owner。

HTML 代码不随打开文档自动运行：编辑和查看时显示静态快照或占位，运行态下由用户点击激活，并受挂载预算限制；在 Block 内出现第一次真实的指针或按键操作之前，`emit` 被拒绝。调用超时、崩溃或无响应时回退到静态快照，不影响其他 Block。重新 build 后旧运行时被卸载，迟到的回调被丢弃；禁用某个 Renderer 后不得继续执行其回调。

任务程序 Worker 的信任前提不同：生成程序由 AI 在运行中产生，未经人工引入就会执行，因此必须按[本地生成程序的隔离](08-任务执行与AI.md#本地生成程序的隔离)隔离。HTML Renderer 不要求同等隔离；两类宿主分别控制生命周期、预算和超时。

宿主 API 采用明确版本。新宿主维持已支持旧 API 的语义；定义升级不能静默改变已有实例的属性、绑定或用户内容。兼容升级保留实例覆盖；不兼容升级通过显式迁移，失败保留最后可用修订。

定义、运行资源及必要静态快照随工作区保存、Fork 和导出。缺失定义、未知版本、不支持的数据类型、依赖不可用和扩展被禁用应分别解释；通用只读视图保留原始数据与引用，不能靠删除未知内容完成打开。

## Block-control 与组合模型

Block 负责一个节点的表现；Block-control 负责一组真实子 Block 的组织、布局、连接和容器级操作。是否需要编排子 Block 是两者的分界，不按视觉复杂程度区分。

组合控件使用通用容器承载定义与实例。客户卡片、按钮组、脑图、看板等组合不因此成为新的数据原语；各节点继续使用 Block 的选择、编辑、权限、批注和连接能力。

### 组合定义

| 内容 | 契约 |
| --- | --- |
| 公开属性 | 声明类型、默认值及到内部表现的映射 |
| 命名绑定 | 将外部数据映射到明确的子 Block 输入；不得通过任意查找兄弟节点建立隐含绑定 |
| 内容 slots | 声明名称、接受的节点类型、数量规则、布局角色及默认内容 |
| 模板外观 | 由容器外观层绘制边框、背景、装饰和隐式边，不冒充用户内容实体 |
| 布局 | 指定受支持算法、输入与可自动计算的几何分量 |
| 动作与事件 | 暴露统一模型中的接口；内部转发须有明确目标与参数 |
| 依赖 | 固定所引用定义与实现资源的版本闭包，拒绝未定义的循环依赖 |

slot 中的用户内容是真实 Block，具有稳定身份。修改控件背景、默认样式或算法不得重建这些节点；移除 slot、改变必填属性或破坏绑定的更新必须显式迁移。

定义只保存可复用结构与初始化约定。实例保存属性覆盖、命名绑定和实际子节点；用户内容不回写定义，不因另一个实例编辑而改变。

### 布局归属与组合操作

父容器拥有直接子节点的布局。Block 可以报告尺寸需求，不能擅自改动兄弟节点位置；嵌套 control 先形成自身尺寸与内部布局，再作为一个节点参与父布局。

布局求解读取明确的子树、配置和测量输入，只产生已声明的自动分量。固定分量由用户或操作设置；算法不能在渲染期间反向提交数据、改变成员关系或反复触发自身。

组合控件可以引用已有布局算法。新增组合类型不要求增加内核 kind；引入任意新算法代码需要通过执行与扩展契约，不能只在配置里填脚本便获得宿主权限。

连接可以是容器根据结构绘制的隐式边，也可以是独立连接线 Block；二者的身份、编辑和导出语义应明确。不能把隐式边当作可独立删除的持久实体。

创建、复制、粘贴、移动、分组和拆分使用统一操作协议。复制通过统一 ID 映射重建组内关系，按所有权规则克隆自有数据或保留共享引用；不能让某一种 control 成为所有粘贴行为的默认包装。

移除被实例或其他定义引用的定义必须处理强依赖。安装来源升级、工作区定义升级和单实例编辑是不同动作；更新本机扩展库不自动更新已引入的工作区定义。

“保存片段”产生插入后独立的内容副本；“定义控件”产生可供多个实例引用和升级的定义；“工作区模板”初始化完整工作区。三者不得共用一个含糊的复制入口。

## 内置 Block 标准库

内置 Block 是宿主契约的标准实现集，不因随系统发行而拥有额外数据权限。它既提供开箱即用能力，也作为扩展开发者实现相同接口的参照。

“原子 Block”指无需编排其他真实子 Block 即可完成其职责的可复用界面单元，不是数据内核原语。原子集合应小而稳定；复合业务界面优先由这些单元与 control 组合。

| 类别 | 代表对象 | 标准库责任 |
| --- | --- | --- |
| 基础呈现 | label、media | 文本/值显示、媒体资源呈现、尺寸与静态替代；保持命名绑定和模式规则 |
| 普通图形 | SVG 图形、Frame | 图形样式、几何、锚点；Frame 提供明确区域与用途，不隐含业务数据所有权 |
| 复杂编辑 | RichText/richedit、Table | 结构化内容编辑、专用协作和稳定子项寻址；复用内核原语，不另造提交历史 |
| 特殊交互 | 连接线、笔迹 | 端点/路径或笔画数据、命中和交互、跨模式表现；保留自身稳定身份与引用规则 |

label 可以显示常量或绑定值，不因显示数值就拥有另一份数值真相。media 以资产或来源引用为正文，播放位置等运行状态与共享资源版本分开。

Table Block 是 Table 数据的视图和编辑器，不把每个数据格变成画布 Block。RichText Block 保留结构化正文、稳定锚点和协作历史，不以 HTML 字符串替代原语。

连接线与笔迹可具有专用命中、编辑和绘制路径，但仍经过公共生命周期、权限、命令、导出和回退协议。“通常不组合”只是使用习惯，不构成绕过宿主契约的例外；确实不能放入某种 control 时，以能力声明和结构校验表达。

Frame 的视觉区域、成员关系、演示目标与打印页用途必须分别声明。把对象移进一个矩形范围，不自动改变其父节点、授权或业务数据归属。

新增标准 Block 原则上增加标准库定义与实现；只有需要新增数据原语、操作或宿主能力时才修改相应核心协议。标准库维护与外部扩展遵循同一版本和迁移原则。
