## Viewport、固定演示与独立会话

实时 Viewport/Follow 属于 Presence；保存的 Viewport、演示路径与默认视角属于共享文档。高频视角更新不进入永久编辑历史，跟随者仍按自己的权限读取内容，Follow 不传送演讲者私有草稿或完整 Session。

固定演示使用一致的基线克隆或相应内容基线，并闭合、保留所需依赖。原 Workspace 随后继续编辑不改变基线；写锁可以服务作者检验效果，但不能替代固定版本机制。直接读实时内容的旧式只读放映必须标明没有固定基线。

演示交互写入自己的状态或分支，不隐式改动原 Workspace。需要带回原文档时，形成新的、可审阅的条件提交。回放同时需要事件和对应基线资源，二者保留期必须协调。

同 ACL 的非公开演示每次读取按原 Workspace 当前授权检查，撤权或停止共享立即影响访问，不能仅依赖创建克隆时复制的 ACL。

公开内容分享和发布采用 ContentRoot 投影，不向接收者交付含完整编辑历史的数据库；公开入口有明确的授权范围与生命周期，不能由“固定版本”推导出永久访问。

独立公开会话按后续 [第四期规划 §3.1、§4 的 Q02/Q14 裁决](<../BuckyOS AI Workspace 第四期规划.md>)处理：服务可以克隆建立运行 Workspace，但必须在开放前裁去创建前协作历史、剥离私有备注、清除原控制状态、重建本场 ACL，并独立保留所需资源。观众经本场授权投影与变更流访问，不获得原 Workspace 访问权；原 Workspace 分享和本场邀请是不同授权，本场撤权须作用于后续读取与回放。这是对早期 D17 尚未展开的公开房间部分的后续收敛，不改变非公开放映追随原 ACL 的规则。

房间参与身份、互动事件和回放由独立会话协议定义；本文冻结其与原文档、运行态和保留的边界，不复制产品层事件协议。无论使用内容快照还是受控运行分支，都不得暴露未授权的历史、凭据和私有状态。

## PDF 导出与打印

打印就是把一个画布导出成一份 PDF 文件（owner 2026-11-14，打印 TODO §1）：产出存入 Zone 或下载到本机，不放回工作区，系统里没有打印机选择、打印队列这类画面，也不调用浏览器的打印对话框。用户要纸质件时用自己设备上的 PDF 阅读器打印。实施记录见 `notepads/aiws-print-pdf-export-todo.md`。

打印针对画布（Surface），入口在画布菜单（文案“导出可打印 PDF”），需要 `export` 能力；数据模式里没有入口，也没有“打印整个工作区”。输入是具有明确版本与访问范围的文档投影、页面配置及资源集合；输出是固定结果，不是截图当前滚动窗口。

这一期 Block 不声明打印能力，Block 的渲染契约不变：服务把要打印的内容物化成一个自包含的打印包（固定基线的、调用者读得到的行，资产，以及用 Desktop 现有 Block 组件构建的打印渲染入口），交给 Workflow 的系统渲染 `media.page`，在 Zone 里用无头 Chromium 分页、排页眉页脚和页码、输出 PDF（打印 TODO §4，owner 2026-11-16 定的路线）。只会输出 HTML 的扩展 Block 与内置 Block 走同一条路。自建渲染管线是长期方向，见[渲染管线方案讨论](<../BuckyOS AI Workspace 渲染管线方案讨论.md>)；换后端时页面模型、PDF Frame、对话框、基线与权限不变。

### 页面规格与 PDF Frame

页面规格在打印时选择：A4、A5、A3、Letter、16:9、4:3，以及纵向或横向。流模式画布默认 A4 纵向，自由画布默认取演示路径的舞台比例。

PDF Frame 是随标准库发行的组合控件（对应早先所说的“背景控件”），是普通控件实例，可以放在任意画布上，一个工作区可以有多个。每个 PDF Frame 有一个页面比例（A 系列共用一个，A3、A4、A5 比例相同），打印时等比缩放到所选的页面规格上，比例一致才可选；不选也能打印。它的页眉、页脚是两个 slot，可以放文本、图片和形状；内容区是页眉页脚之间、左右边距以内的区域。label 可以取“页面上下文”：页码、总页数、标题、日期，由打印宿主在排好页以后给出，在画布上编辑时显示示例值。每页的页眉页脚是同一个实例的投影，不为每页复制数据；PDF Frame 实例本身不作为内容输出。

没有选 PDF Frame 时：流模式的内容区是页面四边各减 20 mm，自由画布的内容区是整页。

### 自由画布：页面取自演示路径

自由画布的页面区域和页序直接取它的演示路径，不另建一套页面定义：需要一条经过本画布的演示路径（`purpose: presentation`，引导路径不算），一步一页，步骤的矩形等比缩放后放进内容区并居中，不裁切、不拆页。没有演示路径时提示无法打印，并引导去建演示路径。沿用放映的规则：步骤声明隐藏的 Block 不出现，停用、目标已删除、落在流模式画布上的步骤跳过并列入问题清单，旋转的 Frame 按不旋转输出，讲稿备注不输出。

演示路径可以跨画布，沿路径可以打印出跨画布的内容；对用户只说打印当前画布，这一点留给愿意研究的用户发现。路径经过调用者读不到或不能导出的画布时，那些步骤跳过并列入问题清单。

修改页序就是修改演示路径，不移动原 Block；一个内容对象可出现在多个页面投影中。许愿格生成或调整页面布局放到后续。

### 流式自动分页

流模式根据内容顺序、可打印宽度和页面高度自动分页。分页在打印包里做：渲染入口在 Chromium 里按内容区宽度渲染各 Block、量出高度和合法断点，再用分页纯函数排页（与测量用同一个引擎、同一套字体），排好以后才输出。

分页点只能落在合法断点上：Block 之间、富文本的段落和行之间、表格的行之间。标题与下一块同页。表格打印全部行，跨页重复表头。单个不可拆分的内容高于一页时等比缩小到一页并列入问题清单；宿主不能通过裁掉溢出部分来伪装完成打印。页眉页脚和边距先从页面高度里扣除，再分页。

### 字体

工作区设置把 `sans`、`serif`、`mono` 对应到具体字体（根节点 `config.fonts`），没有设置时用系统默认字体。默认字体是 ext-core 带的 Noto CJK、DejaVu、Liberation；其他语言的字体以 ext-tool 字体包 `ext-fonts` 提供，包里只声明在线项，节点从上游官方地址下载，我们不分发。进入打印对话框时检查这三个对应的字体在节点上是否就绪；缺失时提示“打印可能失真”并引导安装，不阻止打印，缺失的字体用替代字体输出。屏幕上的字体不因此调整。

### 固定结果与失败行为

开始导出时固定文档、布局、渲染入口和依赖资源的版本：打印包在服务的一次读取里生成，之后的编辑不进入这次输出。图片等资源在排版前备齐，缺失的列入问题清单；字体由节点提供。

打印是一个独立的呈现模式：不运行宏和许愿格，不同步数据源，不播放媒体，不产生任何写入。视频输出封面图，音频输出带名称的占位；HTML 扩展 Block 在打印包里照常运行，读包里的数据，做不到时用它的快照图片。选区、个人折叠状态、评论和批注不输出。主题按页面背景的深浅取浅色或深色，不随 Desktop 当前的主题。

输出范围遵守当前读取与导出权限：只输出调用者读得到的内容，读不到的 Block 留空并计入问题清单，不暴露它的名称；讲稿备注、私有草稿及个人状态不进打印包。

成功表示全部页面都已生成；失败或取消时不写出文件，说明原因及受影响的页。生成的 PDF 只存入 Zone（系统文件选择器的保存模式，同名文件由选择器询问）或下载到本机，不自动登记为工作区资产；用户需要时自己把文件插入画布。
