## Source、同步与按路径发布

### Source 是数据实体的来源属性

Source 为空时，数据由当前 Workspace 内部维护。具有 Source 的实体保存来源、查询范围、版本选择、刷新策略和授权模式；它对普通 Block 编辑只读。修改来源配置与写入同步结果是不同的授权操作。

```text
外部 Workspace / URL / DirObject
             ↓ 获准读取
       暂存并校验候选版本
             ↓ 单次 Commit
     当前 Workspace 的本地数据实体
             ↓ 受控绑定
           Block / API
```

核心业务依赖通过数据实体提供，不让 Block 任意绕过 Source 读取外部业务数据。装饰性外链可以按浏览器策略显示，但不获得离线、固定版本或可重放保证，不能用装饰性资源例外承载核心依赖。

### 首次可用与刷新

首次创建成功表示已有完整的约定结果可靠进入本地存储。可以显示“正在创建”的占位或进度，但不能把未完成下载的源作为可用数据依赖。

刷新作为一次 run，先获得候选内容及资产，校验后以普通 Commit 原子切换，服务推导 `origin: source`。失败、取消或配额不足时保留最近一次有效版本。v1 每个 Source 各自原子，不承诺多个 Source 同时刷新的一致事务。

完整性针对明确的数据切片，不要求复制整个远端数据库。查询范围、分页完成条件、记录身份和源版本共同定义结果。导入 CSV、表格等材料时，应显式表达截断、解析损失和无法保持的结构，不能以静默丢数据换取“导入成功”。

普通 CSV/XLSX 值导入创建内部可写数据，不自动建立 Source、持续刷新或向原文件回写关系。只有显式配置外部 Source 才适用同步只读规则；“导入一次”与“订阅来源”是不同动作。

自动与手动同步只改变刷新时机，Block 读取本地有效版本的方式相同。手动同步源的新鲜度只能表示“基于最后成功同步版本”，不能声称远端没有变化。

### 同步宿主与副本授权

服务侧仅保留无凭据公开 URL 抓取的窄路径，作为 Source 基础设施，不执行用户代码，并计入 Workspace 流量与资源额度。有凭据或需要自定义能力的 Source 使用托管执行，单独授权输入、输出与外部访问。

默认模式是：获授权身份导入内容，再作为当前 Workspace 的独立副本按其 ACL 共享。导入者必须具有这种共享用途的授权。地址与公开策略可进入文档，凭据及其运行绑定属于服务控制状态。

未物化远端查询是另一类能力，按读取者身份访问；必须声明固定源版本、一致分页、稳定记录身份和离线读取等支持情况。它不自动具备本地 Source 的可用性，不计入完整离线快照，v1 不作为通用稳定的数据源接口承诺。

v1 Source 作用于整个实体；“同步列只读、手工备注列可写”需要明确列组模型，不能由某个编辑器私下绕过只读约束。它可作为 Table 后续扩展，不增加新原语。

### 统一读取看到的数据源

[公共属性](02-数据模型与引用.md#公共属性)里的 `data` 区分三种当前真实存在的数据状态，Agent 在写入前据此判断，不能只看 ACL 能力：

| `data.mode` | 含义 | `data.write` | 读取 |
| --- | --- | --- | --- |
| `local` | Workspace 内部维护的数据，包括一次性导入的 CSV/XLSX | `edit`：按调用者能力经 Commit 修改 | 完整 `body`，可被文本查询和 SQL 读取 |
| `synced` | 带 Source 的本地副本 | `refresh`：只有 Source 的刷新写入内容，普通编辑返回 `SOURCE_READ_ONLY`；来源配置、标题和说明仍可修改 | 与本地数据相同，读到的是最近一次有效版本；刷新失败时仍是旧版本，不变成空表 |
| `url_query` | 行在远端、未物化的 URL 表 | `none`：没有本地行可写 | `body` 只给表定义和来源说明（`state: definition`）；文本查询只覆盖名字和定义，并在 `coverage.skipped` 里以 `definition` 列出；SQL 返回 `NOT_MATERIALIZED`；行读取走 internal 方法 `doc.source_query`，参数沿用原表格查询的 filter、sorts、fields 和 `source_revision` |

`data.source` 是来源配置的摘要（种类、模式、地址或来源实体、刷新设置），只给已记录的值；凭据不在其中。“尚未取得有效数据”“正在首次同步”等状态目前没有独立表示，统一读取不伪造它们；后续由 Source 生命周期扩展时同步加入公共属性。支持远端回写的来源尚不存在，没有对应的 `write` 取值。

### 按数据路径发布

发布的基本单位是指定数据源或产物目录。发布方对该范围建立公开读入口，返回规范引用及其 URL 投影；其余内容与 ACL 不因此公开。读取、导出和发布是不同能力。

消费方可把链接插入为 Source：同 Zone 可由服务直接读取；跨 Zone 的公开内容走无凭据抓取。默认 live 跟随发布入口，fixed 解析为被保留的实体内容对象或 ContentRoot，不向消费方交付整库克隆。

“公开当前数据源”和“发布一组已确认结果”要明确区分。业务需要审核或配套资产一致性时，应以输出通道指向已确认快照；先准备完整结果集，再切换一个发布根。上游继续编辑工作稿不自动改动已确认输出。产物目录可直接以 DirObject 作为输出契约。

发布方能够查询已登记的引用者。同服务通过跨 Workspace 引用索引登记；跨 Zone 由消费方登记订阅关系。登记是弱关联，不阻止撤回；未登记访问只能作为访问记录，不能声称掌握所有复制和下游使用。

撤回使原公开入口、live 解析和后续刷新不可用，不远程抹除已经合法导入的独立副本。消费方保留上次有效内容并显示来源不可用；其本地副本仍按导入授权和自身 ACL 管理。仅持有远端 fixed 身份、没有独立副本或保留承诺的调用者，也不能据此绕过撤权。

## Source Adapter 与同步脚本

数据源的数据类型由有限数据原语及业务 Schema 表达；Source adapter 定义外部来源如何解析、读取和物化，不为每个外部服务增加一种内核类型。Block 读取工作区内同一类型的数据，不直接依赖某个连接器的私有 API。

### Adapter 契约

| 声明 | 约束 |
| --- | --- |
| 连接与查询配置 | 地址、查询、参数及输出类型具有可校验结构；敏感凭据使用受控引用 |
| 读取能力 | 明确固定版本、一致分页、稳定记录身份、增量读取及离线支持情况 |
| 结果边界 | 明确完整数据集或查询切片，不能把未完成分页的内容宣称为完整结果 |
| 刷新规则 | 手动或获准定时触发、超时、失败、重试与取消语义 |
| 身份与资源 | 指定读取身份、执行环境、网络能力、费用承担者和预算 |
| 副本授权 | 明确本地副本是否可按 Workspace ACL 共享，不由远端读取权限自动推导 |

Adapter 沿用[Source、同步与按路径发布](04-数据源发布与同步.md#source同步与按路径发布)中的首次可用、刷新原子切换和失败保留规则，不另设绕过提交准入的同步协议。

来源配置、公开查询与 adapter 实现可随文档携带；凭据、在线委托及定时任务的有效授权不随导出或工作区 Clone 复制。导入、Clone 或迁入新部署后，需要目标环境重新建立适用授权。正常重开已授权的在线工作区沿用仍有效的调度与授权；打开页面本身不额外触发一次同步。

### 自带同步脚本的执行

同步脚本可以复用宏语言和部分对象 API，但其执行形态是托管任务。它绑定确定的 adapter/程序修订、输入配置、输出 Source、身份与能力，不能作为任意代码嵌入数据内核的 Apply 或 Get。

服务内仅保留无凭据公开 URL 抓取的有限路径，不执行用户同步代码；有凭据、需要联网工具或自定义解析的任务进入统一托管运行协议。同步脚本需要的后端环境由执行平台提供，不为扩展再建立一套拥有系统身份的脚本宿主。

执行器通过受控能力读取外部内容并生成候选结果，提交端检查 run/attempt、当前授权、配置摘要、输出范围、资产和版本条件，再赋予合法同步写入语义。脚本不能靠填写 `origin: source` 绕过只读实体或其他权限。

Source 内容对普通 Block 编辑保持只读；同步任务只写声明的结果范围。若需要“同步字段 + 本地备注”等混合数据，应使用明确的组合模型或将来的列组 Source，不由 adapter 私自开放部分字段或修改类型规则。

定时刷新必须有明确宿主、资源额度与暂停/失效状态；保存一个周期值不等于已有后台调度。缺少凭据、委托失效、程序修订变化或执行环境不可用时，停止本次执行并报告原因，不借用服务或其他用户的身份继续运行。

同步 run 的重试、幂等、取消和结果未知沿用统一任务协议。远端接口的副作用另行声明与核实；历史重放、恢复备份或复制 Source 均不重新调用外部接口。
