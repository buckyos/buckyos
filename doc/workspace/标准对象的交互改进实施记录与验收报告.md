# 标准对象的交互改进：实施记录与验收报告

> 日期：2026-10-07。对应设计：[标准对象的交互改进](<标准对象的交互改进.md>) v0.2（S1–S3）。
>
> 环境：独立运行的 `aiworkspace` 服务（调试构建）+ Vite 开发服务器，Desktop 外壳使用模拟运行时，Chromium（Playwright）。没有在 DV 或真实 Zone 上运行。

## 1. 结论

S1（外观与状态层）、S2（工具栏与编辑态）、S3（旋转与锁定）已经实施。画布对象静止时不再有宿主白框；hover 显示实线轮廓和类型声明的附件；选中显示圆形角手柄、边缘缩放区和旋转柄；就近工具栏改为图标，富文本、表格、便签、锁的工具从 Block 内迁到工具栏；许愿格在右侧面板中打开；旋转写入 `placement.rotation`，锁定写入 `locked`，协议升到 0.2、格式升到 0.3。

S4（连接线交互）已随连接线实施，见 [连接线实施记录与验收报告](<连接线实施记录与验收报告.md>)。S5 的各项没有实施。

与设计的差异记在设计 §13（13-1 至 13-21）。其中最需要注意的是 13-15：按第二期以来的既定做法，格式 0.2 的工作区存储和导出包会被拒绝。**部署新版本之后，旧版本创建的工作区不能再打开**，DV 上的测试工作区也一样。

## 5. 实测中发现并修正的问题

| 问题 | 后果 | 修正 |
| --- | --- | --- |
| 表格单元格是按钮，画布把任何按钮都当作编辑器 | 表格中部 hover 不出现；只读单元格是禁用按钮，按下后既不能选中，也不能双击进入编辑 | hover 只排除真正的编辑区；禁用按钮不再挡住画布手势（13-17） |
| 表格的静态视图和编辑器都读取“打开面板”的意图 | 静态视图先把意图用掉，编辑器挂载后不打开新增表单 | 只有编辑器读取 |
| 选中框整体框的测试标识以 `aiws-selection-` 开头 | 按前缀数选中框的原有用例多数一个 | 改为 `aiws-multi-selection` |
| 旋转柄按下即捕获指针，双击事件落到画布根上 | 双击旋转柄进入了形状文字编辑，而不是归零 | 用两次按下的间隔识别双击；按手柄后的画布双击不进入编辑 |
| 旋转 90° 后旋转柄落在选区上方 | 被就近工具栏盖住 | 工具栏同时避开旋转柄 |
| 便签编辑中按 Esc 放弃输入 | 与富文本不一致，打字后 Esc 丢失内容 | Esc 保存后退出（13-8） |
| 从 hover 附件打开编辑器时对象没有被选中 | 没有选中框和工具栏 | 进入编辑时同时选中 |
| 流式页没有就近工具栏，图片也被画成“只有图片” | 文件信息和“替换…”消失 | “只画内容”只用于自由画布 |
| 新插入的许愿格在 Block 内打开 | 与 R6 不一致 | 插入后直接在右侧面板打开（13-21） |
| 深色主题下浅色填充的形状上文字不可见 | 文字看不见 | 按填充色亮度选文字颜色（13-11） |

## 6. 未完成与风险

- **旧工作区不能打开（13-15）。** 部署后，格式 0.2 的工作区存储与导出包都被拒绝。DV 上已有的测试工作区需要先用旧版本导出，或者接受丢弃；如果要保留，可以让新内核读取 0.2（只是版本标记不同，数据是 0.3 的子集），但这属于向下兼容，没有做。
- 已打开的旧页面在本次升级后不会提示刷新：版本识别的代码在新版本里，旧页面没有。
- S5 各项（S4 已随连接线实施）、键盘旋转、分组旋转、便签颜色的 hover 附件、HTML 扩展 API v3：未实施。
- 输入法组合输入不能直接开始编辑（13-16）。
- 平板只验证了手柄尺寸与附件，触摸缩放、旋转手势没有自动化；没有真机。
- 浅色、深色主题只截图人工看过，没有像素对比；200% 浏览器缩放没有验证。
- 没有在 DV / 真实 Zone 运行；性能对比只有一次运行。
