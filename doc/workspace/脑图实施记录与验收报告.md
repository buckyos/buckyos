## 1. 结论

- **M0–M4 已实施。** 脑图是第一个 Block-control：容器 `kind = mindmap`，节点是普通 Cell（`parent_id` 即父子，`order_key` 即兄弟序），边由容器画、不存储。placement 的 `x`/`y`/`w`/`h` 各自可为 `"auto"`，由共享 TS 模块的 `tree` 布局在显示时算出；写数值即 pin，写回 `"auto"` 即“回到自动布局”。
- **内核（PROTOCOL 1.1）**：`mindmap` 容器、`"auto"` 分量（只在 control 内；非文字节点尺寸须为数值）、control 内 Cell 可有子 Cell、`slot`（同父唯一，`SLOT_CONFLICT`）、outline 投影（control 的 `config`，Cell 的 `slot` / `side` / `branch_color`）。1.0 请求照常接受（`supports_protocol`）。WASM 已重建。
- **共享模块 `src/frame/aiworkspace/controls/`**（浏览器与 Deno 同用）：布局（四方向、折叠、pin、嵌套自底向上）、文字测量、隐式边、Markdown 大纲 / OPML 互转、静态 SVG、draw.io 物化、control 目录与给 Agent 的自述。
- **Desktop**：插入、渲染（边、折叠柄、pin 标记、嵌套框）、键盘（Tab / Enter / 方向键 / Ctrl+/ / Ctrl+D / Delete）、拖动重挂与实时预览、pin 与回到自动布局、拒绝拖出、复制粘贴子树、容器与节点工具栏、流式页整体渲染、富文本 ⇄ 脑图、Markdown / OPML 导出、OPML / Markdown 文件导入、draw.io 导出物化、未知 kind 降级、手机只读与折叠。
- **Agent 与许愿格**：许愿格新增通用 `control` 结果（模型 `put_result` 与程序 `aiws.result.control`，可 `under` 扩展某个节点），control 目录以 `catalog/controls.json` 给模型；服务新增 `control.list / describe / import / export`；websdk CLI 新增 `buckyos aiws controls list|describe`、`import`、`export`；两份手册已更新。
- **真实 Zone DV（10-28，§8）**：浏览器 3 项（fixture 与双账号折叠、`control.*` 经网关、真实模型许愿得到脑图）全部通过；系统 CLI 的 `controls` / `import` / `export` 对真实服务跑通（顺带修了 `controls list` 的参数解析）；Jarvis 只凭手册在指定画布上建图并在原图上扩展分支（M3 完成条件），第一次因容器内连不上 nfs-server（与脑图无关的环境问题）中断。
- 性能：1,111 节点的脑图加 10 层嵌套 control，生产构建首屏 319 ms，折叠后重新布局 54 ms，平移 p95 16.8 ms，无长任务（§4.3）。

## 5. 实测中发现并修正的问题

- 选中节点时，四个连接柄正好压在折叠柄上，点不到折叠柄（MM02 首次失败）。节点不再显示连接柄，关系线用连接线工具画。
- 折叠柄原先画在世界坐标里，缩小后变成几像素，被缩放手柄的边缘热区盖住。改到屏幕坐标的浮层，大小固定，避开缩放热区。
- 文字节点的“回到自动布局”在工具栏和“更多”里各出现一次，测试 id 冲突。只保留工具栏里的一份。
- 嵌套在节点里的脑图原来没有外框，指向它的边停在半空。现在画一条浅色虚线框。
- （10-28 追加拖入时发现）拖动预览把被拖对象的“落下后的 placement”只写进了 `get`，而布局读的是 `childrenOf` 给出的子项：拖入的画布对象按原坐标被当成 pin，预览虚线指到画布远处；节点 pin 预览里兄弟也没有让位。两处都改为同一个 `asDropped`。

### 8.4 其他观察（未改）

- 许愿格结果即使只有 control，也会在输出容器里建一个以 `output.name` 命名的数据文件夹；若许愿格自己的名字与 `output.name` 相同，预检报 `name … already used` 并禁用“应用”（行为正确，DV 用例起初就是这样配错的）。
- control 不带 `derived` 记录（内核只允许数据实体带），由许愿格 `last_run.result_bindings` 绑定。
- 双击许愿格会触发浏览器文字选区，应用结果后选区覆盖了新插入的节点文字（蓝色高亮）；与脑图无关。
- 1280×720 视口、28% 缩放时，选中节点的浮动工具栏会盖住整张小图，选中小节点时四个缩放柄挤成一团；在 1600×1000 下正常。
