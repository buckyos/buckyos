# 自备证书：买哪种、怎么上传

使用自有域名时，证书可以由系统自动签发（Let's Encrypt，免费，自动续期），也可以上传自己的。DNS 选“手工管理”时只能上传。

下面以 Zone 域名 `home.example.com` 为例。

## 1. 需要哪两个名字

证书的“使用者可选名称”（SAN）里要同时有：

- `home.example.com`
- `*.home.example.com`

应用、`sys`、`ood1` 都是一级子域，而且会新增，所以第二个名字必须就是 `*.home.example.com`，逐个列出子域名不行。只看 SAN，不看 CN。

可以是一张证书同时包含两个名字，也可以两张证书各包含一个。

| 你手上的证书 | 能不能用 |
| --- | --- |
| SAN 有 `home.example.com` 和 `*.home.example.com` | 能 |
| `*.example.com`（Zone 域名是 `home.example.com`） | 不能。它覆盖 `home.example.com`，但不覆盖 `notes.home.example.com` |
| 单域名证书（`example.com` 加 `www.example.com`） | 不能，没有通配名，应用打不开 |
| 只有 `*.home.example.com` | 不够。通配名不包含域名本身，再传一张 `home.example.com` 的，或让 CA 加进 SAN |
| EV 证书 | 不能。行业规则不允许 EV 用通配名 |

## 2. 买哪种

- **DV 或 OV 的通配证书（Wildcard）。** 两种都可以。
- **下单时确认 SAN 里两个名字都有。** 不要只填 `*.home.example.com`。页面上没写清楚的，问 CA 会不会把 `home.example.com` 加进去。
- **密钥类型：** RSA 2048 位以上，或 ECDSA P-256、P-384。不要用 P-521。
- **不要买 EV。** 见 [CA/B Forum EV 指南](https://cabforum.org/working-groups/server/extended-validation/documents/CA-Browser-Forum-EV-Guidelines-2.0.4.pdf)。

### 有效期在缩短

公共 CA 签发的证书，最长有效期（[来源](https://www.ssl.com/article/ssl-certificate-validity-changes-what-you-need-to-know/)）：

| 签发日期 | 最长有效期 |
| --- | --- |
| 2026-03-15 起 | 200 天 |
| 2027-03-15 起 | 100 天 |
| 2029-03-15 起 | 47 天 |

买的时候按“年”卖，也要在到期前向 CA 重新领证书，再来换。嫌麻烦的用自动签发。

## 3. 申请和下载

1. 在自己的电脑上生成私钥和 CSR，私钥不要发给任何人：

   ```bash
   openssl req -new -newkey rsa:2048 -nodes \
     -keyout home.example.com.key -out home.example.com.csr \
     -subj "/CN=home.example.com" \
     -addext "subjectAltName=DNS:home.example.com,DNS:*.home.example.com"
   ```

   也可以用 CA 网页上的工具生成，记得保存私钥。
2. 把 CSR 交给 CA，按它的要求验证域名。
3. 下载证书和中间证书。选 PEM（Nginx / Apache）或 PFX（Windows / IIS）都可以。

看一下内容对不对：

```bash
openssl x509 -in home.example.com.crt -noout -issuer -dates -ext subjectAltName
```

## 4. 上传

- **激活时：** 域名步骤，证书选“上传”。
- **激活后：** Desktop 的“设置”>“Zone 配置”，在“域名与证书”里点“替换证书”。需要 Zone 所有者，并输入密码确认。

接受的内容：

| 格式 | 要什么 |
| --- | --- |
| PEM | 证书、中间证书、私钥。一个文件、多个文件或粘贴文本都行，顺序不限 |
| PFX / P12 | 一个文件和密码 |

PEM 私钥不能带密码。带密码的先去掉：

```bash
openssl pkey -in encrypted.key -out plain.key
```

PFX 打不开的可以先转成 PEM（旧系统导出的加 `-legacy`）：

```bash
openssl pkcs12 -in home.example.com.pfx -nodes -out home.example.com.pem
```

上传后逐项检查：

| 检查 | 不通过时 |
| --- | --- |
| 文件能打开，PFX 密码正确 | 不能继续 |
| 私钥与证书是一对 | 不能继续 |
| SAN 有 `home.example.com` | 不能继续 |
| SAN 有 `*.home.example.com` | 不能继续 |
| 在有效期内 | 过期或还没生效：不能继续，并显示节点的时间。剩余不到 30 天：确认后继续 |
| 用途含服务器认证 | 不能继续 |
| 不是 CA 证书 | 确认后继续 |
| 证书链能连到公共根证书 | 确认后继续。常见原因是漏传了中间证书 |
| 密钥算法支持 | 不能继续 |

私钥只存在节点本机，不上传到别处。

## 5. 到期前自己换

上传的证书，系统不续期、不提醒、不替换。过期后浏览器打不开。请在到期前换：

1. 向 CA 领新的证书。
2. 在“设置”>“Zone 配置”上传。1 分钟内新连接用上新证书，网关不用重启。

以后想改成自动签发，也在这里切换。手工管理 DNS 的要先换成 SN 托管或 DNS API。

备份 Zone 时会带上证书和私钥。丢了要向 CA 重新下载或重签。

## 6. 自签证书和私有 CA

可以上传，用于测试。只有信任它的设备能连：

- 没装这个 CA 的浏览器和手机会报不安全。
- 其它 Zone 解析不了本 Zone 的身份，跨 Zone 功能不能用。
- BuckyOS App 连不上。
- 激活后页面可能检测不到启动成功，需要自己打开确认。
